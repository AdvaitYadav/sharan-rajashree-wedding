# Cashback Tracker

Mobile-friendly personal cashback tracker for Advait and Gourav at https://sharaninvites.in.

Log in, select a person, edit a draft and submit to save a dated session. The dashboard displays each submitted session by card. Expected cashback minus charges gives net cashback; actual cashback starts at the same net amount and can be edited later.

Only browser assets are included in this public repository. Authentication and Google Sheets storage run on a separately deployed backend. No login credentials, private sheet identifier, backend source or personal records are included here.
